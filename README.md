## 🚀 Getting Started

### Prerequisites

- A modern web browser (Chrome, Firefox, Safari, Edge)
- Git installed on your machine

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/rashedjamanraju/Portfolio-Website.git
   cd Portfolio-Website
   ```

2. **Open locally:**
   - Simply double-click `index.html`, or
   - Use a local server (recommended):
     ```bash
     # Using Python 3
     python -m http.server 8000
     
     # Using Node.js (http-server)
     npx http-server
     ```

3. **View in browser:**
   - Navigate to `http://localhost:8000` (if using a local server)
   - Or open `index.html` directly

## ⚙️ Configuration

### Contact Form Setup

To enable the contact form and newsletter subscription:

1. Create a [Google Apps Script](https://script.google.com/) Web App
2. Deploy it as a web app and get your deployment URLs
3. Replace the endpoints in your JavaScript: 

```javascript
const CONTACT_ENDPOINT = "YOUR_CONTACT_SCRIPT_URL";
const SUBSCRIBE_ENDPOINT = "YOUR_SUBSCRIBE_SCRIPT_URL";
```

### Customization

- **Personal Info:** Update details in `index.html`
- **Styling:** Modify colors and fonts in `styles/style.css`
- **Images:** Replace images in the `images/` directory
- **Content:** Update text content for projects, skills, and achievements
