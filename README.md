## ✨ Features

- ✅ Fully responsive design (desktop, tablet & mobile)
- ✅ Sticky navigation with auto hide/show on scroll
- ✅ Hamburger menu for smaller screens
- ✅ Animated hero section and smooth UI transitions
- ✅ Well-structured sections:
  - Work Experience
  - Achievements
  - Skills
  - Problem Solving Activities
  - Projects
  - Education
- ✅ Contact form powered by Google Apps Script
- ✅ Newsletter subscription in footer
- ✅ SEO-friendly and accessible HTML markup
- ✅ Modern layout using CSS Grid & Flexbox

```bash

```
